Carpeta "src/lib"

Esta carpeta contiene los módulos de conexión y comunicación de Facturapp.

Archivos que se agregarán aquí:

- "supabase.ts": inicialización del cliente de Supabase.
- "chat.ts": llamadas a la función "chat-api".
- "chat.test.ts": pruebas del módulo de chat.

No coloques claves secretas ni la clave "service_role" en el frontend.
